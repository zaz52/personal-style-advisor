# Personal Portrait Photography / Lifestyle Shot

Use this reference when the user wants one realistic portrait or lifestyle photo rather than a consulting report board.

## When To Use

Use for requests like:

- 真实照片 / 像摄影师拍的
- 咖啡馆人像 / 街拍 / 旅行照 / 约会头像
- 鱼眼镜面 / 复古闪光灯 / 胶片感
- 小红书头像 / dating profile photo / personal branding portrait

Do not use for diagnostic boards, before/after analysis reports, or product recommendation infographics.

## Prompt Skeleton

```text
Create one realistic personal portrait photograph of the same person from the uploaded reference image.

Task / output type:
One finished photo, not a collage, not a report, not a poster with labels.
Aspect ratio: [3:4 / 4:5 / 9:16 / 1:1].

Identity preservation:
Use the uploaded reference photo as the primary identity source. Keep the same face shape, eyes, nose, lips, skin tone, age impression, hairline, expression temperament, and body proportion. Do not create a generic influencer face.

Scene:
[exact location: retro cafe / city street / elevator mirror / bookstore / hotel lobby / rainy window / tennis court / night street].

Camera and lens:
[35mm documentary / 50mm natural portrait / 85mm shallow-depth portrait / fisheye close-up / direct-flash film snapshot].
Specify camera distance: [close-up / half-body / full-body].
Specify viewpoint: [eye-level / slight low angle / mirror reflection / over-the-table intimate POV].

Styling:
Outfit: [keep original clothing / upgrade to a specific clean outfit].
Hair and makeup/grooming: [natural, realistic, matched to the person's temperament].
Accessories: [glasses / jewelry / bag / watch / none].

Lighting and texture:
[soft window light / warm cafe pendant lights / harsh direct flash / neon reflections / golden hour / overcast street light].
Real skin texture, natural pores, subtle film grain, realistic fabric texture, unified shadows.

Mood:
[quiet confidence / relaxed daily / fresh sporty / cinematic city / intimate cafe / clean editorial].

Strict avoid:
No report cards, no text labels, no fake brand logos, no face replacement, no plastic skin, no extreme smoothing, no aggressive slimming, no unnatural body proportions, no oversexualized pose, no messy extra fingers, no unrelated props.
```

## Stable Patterns

### Retro Cafe Fisheye Mirror

```text
A fish-eye lens close-up of the same person from the uploaded reference image, leaning forward toward the camera while holding a teal coffee mug, shot through or near a round mirror. Retro cafe interior with glossy teal subway tiles, vintage appliances, pendant lights, warm moody tones. Natural skin texture, realistic face consistency, intimate but tasteful composition, no text.
```

### Direct Flash Sporty Snapshot

```text
A realistic 35mm color film direct-flash portrait of the same person from the uploaded reference image in a sporty outdoor setting. Strong catchlights, visible fabric texture, natural skin pores, subtle film grain, high-contrast flash look, relaxed confident pose, realistic body proportions, no plastic retouching, no text.
```

### Clean Profile / Dating Photo

```text
A natural 50mm half-body portrait of the same person from the uploaded reference image, soft window light, clean outfit, relaxed posture, warm neutral background, approachable expression, realistic skin texture, subtle editorial polish, suitable for a profile photo, no text or labels.
```

## Verification

- The result is one photo, not a report board.
- The person still looks like the reference image.
- Lens, lighting, scene, styling, and mood are all specified.
- Any styling upgrades stay believable and identity-preserving.
