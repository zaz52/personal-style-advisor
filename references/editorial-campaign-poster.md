# Editorial / Campaign Poster Mode

Use this reference when the user wants a shareable fashion poster, magazine cover, sports/fashion campaign, typography-led personal poster, or artistic portrait rather than a consulting diagnosis board.

## When To Use

Use only for requests like:

- 做成杂志封面 / fashion magazine cover
- 高级个人海报 / personal editorial poster
- 运动时尚大片 / sports fashion campaign
- 水墨双重曝光人物海报 / ink double-exposure portrait
- 品牌 campaign / 三联画 / poster visual

Do not use this mode when the user asks for a diagnostic report, style recommendation chart, color analysis, or Before/After consulting board.

## Core Difference From Report Mode

Report mode explains and compares. Campaign mode sells a visual identity.

- Report mode: modules, labels, suitable/try/avoid, analysis.
- Campaign mode: one strong hero, exact typography, controlled composition, mood, identity, and shareability.

## Composition Types

Choose one composition type before writing the prompt.

### Single Hero Editorial Poster

One dominant portrait or full-body shot, strong negative space, exact small title or name, premium magazine styling.

### Three-Panel Campaign

A large hero panel plus two smaller supporting panels. Useful for sport, fashion, outfit, or personal branding.

Structure:

- Top / left large panel: hero shot, 50-65% of canvas.
- Smaller panel 1: close-up portrait or accessory/detail.
- Smaller panel 2: full-body pose or movement shot.
- Unified color grading, same person, same outfit family, same typography system.

### Typography-Led Poster

Big exact word or phrase becomes the visual structure. The person interacts with the typography by overlapping, emerging from, standing behind, casting shadow, or breaking through the letters.

Rules:

- Spell the exact title correctly.
- Do not add extra large text.
- Typography must be the hero, not a random label.

### Ink Double-Exposure Portrait

A vertical 9:16 poster with a large recognizable upper silhouette and a smaller full-body/half-body figure below. Inside the silhouette, blend symbolic scenes, fashion motifs, personal story cues, city texture, or seasonal imagery.

Rules:

- Large negative space.
- Ink diffusion, mist, soft fading, layered depth.
- Smooth top-to-bottom visual flow.
- Do not make a hard collage.

## Prompt Skeleton

```text
Create one finished premium [COMPOSITION TYPE] featuring the same person from the uploaded reference image.

Use the uploaded reference photo as the primary identity source. Keep the same face shape, eyes, nose, lips, skin tone, age impression, expression temperament, and body proportion. Do not create a generic model.

Purpose: [magazine cover / personal branding poster / sports fashion campaign / ink double-exposure poster]
Aspect ratio: [9:16 / 4:5 / 1:1 / 16:9]
Exact text, if any: "[TEXT]". Text must be readable and spelled exactly. Do not add unrelated text.

Composition contract:
[Pick one and specify panel sizes, hero placement, negative space, typography placement, and visual flow.]

Styling:
[Outfit / hair / makeup / glasses / accessories. Keep styling consistent with the person's temperament and the selected style profile.]

Visual system:
[Palette, background, lighting, lens, material, texture, typography mood, accent color.]

Quality:
Premium fashion editorial, high-end campaign visual, realistic skin texture, unified light, refined composition, strong hierarchy, shareable finished poster.

Avoid:
diagnosis-board layout, cluttered cards, fake brand logos, unrelated text, misspelled typography, copied campaign, face replacement, plastic skin, aggressive body change, low-end collage, too many stickers.
```

## Useful Visual Patterns

- Sports campaign: oversized prop as diagonal composition skeleton, reflective floor, bold background word, clean high-contrast lighting.
- Fashion magazine: one large full-bleed portrait, restrained serif/sans typography, wide margins, exact cover lines only if requested.
- Personal brand: central portrait, subtle iconography, exact name/title, refined color palette, business/editorial polish.
- Ink double exposure: large upper face silhouette, lower full-body figure, symbolic interior scenes, mist/ink/negative-space connection.

## Safety And Rights

Do not imitate a real brand campaign too closely, do not add copyrighted logos unless the user supplies them and has rights, and do not imply endorsement by real brands.
