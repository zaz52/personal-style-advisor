# Single-Image Five-In-One Overview Example

```text
使用 personal-style-advisor。
我会上传一张清晰正面或半身照片。请使用强参考本人模式，把这张照片作为主要身份参考，生成一张横向的「AI 个人风格五合一适配报告」。

五个模块必须出现在同一张图片上：
1. 眼镜适配
2. 发型升级
3. 衣品升级
4. 色彩诊断
5. 五官氛围 / 妆容细节

要求：
- 必须像上传照片本人，不要变成模板网红脸。
- 保留脸型、眼睛、刘海/发际线、肤色观感和原本气质。
- 五个模块放在同一张图里，不要分成多张。
- 中文文字只用短标签，避免长段落。
- 风格要像高级小红书风格报告，干净、精致、有留白。
- 不要医美承诺，不要羞辱长相，不要夸张瘦脸和塑料皮肤。
```
