# Single-Image Master-And-Modules Overview Example

```text
使用 personal-style-advisor。
我会上传一张清晰正面或半身照片。请使用强参考本人模式，把这张照片作为主要身份参考，生成一张横向的「AI 个人风格五合一适配报告」。

布局要求：
- 不是五个等宽栏目。
- 画面必须有一张大主图，用来代表整体适配后的风格定调，占画面约 40-50%。
- 主图旁边和下方放五个详情模块，每个模块代表 skill 里的一个报告部分。

五个详情模块：
1. 眼镜适配：小型 before/after 眼镜卡，包含适合 / 可尝试 / 不建议。
2. 发型升级：当前发型与推荐发型小卡，包含刘海、侧边层次、发尾、避雷方向。
3. 衣品升级：风格标签、单品拆解、比例优化、可购买关键词。
4. 色彩诊断：最佳色、可尝试色、不建议色、妆容/发色提示。
5. 五官氛围：眉眼唇肤质细节优化，偏自然妆容，不做医美承诺。

人物要求：
- 必须像上传照片本人，不要变成模板网红脸。
- 保留脸型、眼睛、刘海/发际线、肤色观感和原本气质。
- 主图和各模块里的小人像都必须是同一个人。

视觉要求：
- 高级小红书风格报告，奶油/浅粉/黑色点缀。
- 有清晰层级：主图最大，模块为辅助说明。
- 中文文字只用短标签，避免长段落。
- 不要拥挤，不要 PPT 表格感，不要塑料皮肤，不要夸张瘦脸。
```
