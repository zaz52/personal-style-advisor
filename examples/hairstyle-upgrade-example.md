# Hairstyle Upgrade Example

```text
使用 personal-style-advisor。
请基于我上传的正面照片，生成一张横向 4:3 的「AI 发型美学升级报告 / Before & After Hairstyle Upgrade Report」。

要求：
- 严格保留我的脸部辨识度、五官结构、脸型比例、年龄感、皮肤质感、表情气质和原有穿搭。
- 本次只改变发型：长度、刘海、头顶蓬松度、两侧体积、层次、发尾质感和自然发色。
- 不要改变五官，不要瘦脸，不要磨皮美颜，不要换衣服，不要靠妆容提升效果。
- 左侧 Before 保留原始发型状态。
- 右侧 After 给出最适合的主推发型。
- 下方展示 4 个推荐发型、3 个不推荐发型和 Hair Style Guide。
- 整体像高端发型顾问提案板 + 杂志型视觉编排，专业但有一点轻度避坑趣味。
```
