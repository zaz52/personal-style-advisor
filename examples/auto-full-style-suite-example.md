# Auto Full Style Suite Example

```text
使用 personal-style-advisor。
我会上传一张清晰正面或全身照片。请自动识别我的脸型、五官量感、肤色倾向、身材比例、气质方向和当前穿搭基础，然后自动匹配最适合我的完整风格方案。

请不要只做单项建议，而是生成一套完整的「个人风格全案 / Auto Personal Style Suite」。

需要包含：
1. AI 眼镜风格适配报告
2. AI 衣品升级改造报告
3. 四季韩系潮牌穿搭指南
4. 个人色彩诊断三连图
5. AI 发型美学升级报告
6. AI 五官美学升级报告

执行要求：
- 所有报告都必须基于同一张上传照片。
- 所有人物都必须是同一个人，不能换脸，不能变成模板网红脸。
- 先自动判断适合我的风格主轴，再分别套用到眼镜、穿搭、色彩、妆发、发型和五官美学中。
- 如果直接生成图片，请分批生成，不要一次塞进一张图。
- 如果先输出提示词，请按报告类型分组输出，每组包含比例、核心提示词、负面提示词和使用说明。
- 所有建议要实用、尊重、可执行，不要羞辱长相或身材。
```
