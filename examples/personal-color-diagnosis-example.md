# Personal Color Diagnosis Example

```text
使用 personal-image-style-advisor。
请基于我上传的人像照片，生成一套「个人色彩诊断三连图 / Personal Color Diagnosis Series」。

请生成 3 张独立竖版 3:4 成品图：
1. 个人色彩 × 风格总诊断页
2. 色彩上身效果 × 穿搭应用页
3. 妆容 × 发色 × 细节优化页

要求：
- 不要预设我是任何季型，请根据照片自动判断。
- 不要默认奶茶色、豆沙色、暖调、柔秋或韩系温柔风。
- 三张图必须是同一个人，同一种诊断逻辑，同一种视觉语言。
- 给出核心推荐色、延展尝试色、慎用色、穿搭公式、妆容、发色和配饰建议。
- 专业但通俗，要让人看懂为什么，以及日常怎么用。
```
